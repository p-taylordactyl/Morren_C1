# Scroll of Protection
*Scroll, rare*  
![](CLI/items/img/scroll-of-protection.webp#right)


Each Scroll of Protection works against creatures of a specific creature type chosen by the DM or determined by rolling on the following table.

| dice: 1d100 | Creature Type |
|-------------|---------------|
| 01-10 | [Aberrations](CLI/items/scroll-of-protection-aberrations-xdmg.md) |
| 11-15 | [Beasts](CLI/items/scroll-of-protection-beasts-xdmg.md) |
| 16-20 | [Celestials](CLI/items/scroll-of-protection-celestials-xdmg.md) |
| 21-25 | [Constructs](CLI/items/scroll-of-protection-constructs-xdmg.md) |
| 26-35 | [Dragons](CLI/items/scroll-of-protection-dragons-xdmg.md) |
| 36-45 | [Elementals](CLI/items/scroll-of-protection-elementals-xdmg.md) |
| 46-50 | [Humanoids](CLI/items/scroll-of-protection-humanoids-xdmg.md) |
| 51-60 | [Fey](CLI/items/scroll-of-protection-fey-xdmg.md) |
| 61-70 | [Fiends](CLI/items/scroll-of-protection-fiends-xdmg.md) |
| 71-75 | [Giants](CLI/items/scroll-of-protection-giants-xdmg.md) |
| 76-80 | [Monstrosities](CLI/items/scroll-of-protection-monstrosities-xdmg.md) |
| 81-85 | [Oozes](CLI/items/scroll-of-protection-oozes-xdmg.md) |
| 86-90 | [Plants](CLI/items/scroll-of-protection-plants-xdmg.md) |
| 91-00 | [Undead](CLI/items/scroll-of-protection-undead-xdmg.md) |
^1-creature-type

Using a [Magic](CLI/rules/actions.md#Magic) action to read the scroll creates a 5-foot Emanation originating from you. For 5 minutes, creatures of the specified type can't enter or affect anything in the area. However, if you move in such a way that a creature of the specified type would be inside the area, the effect ends.

As a [Magic](CLI/rules/actions.md#Magic) action, a creature within 5 feet of the Emanation can attempt to overcome it, which forces the creature to make a DC 15 Charisma saving throw. On a successful save, the creature ceases to be affected by the Emanation.
