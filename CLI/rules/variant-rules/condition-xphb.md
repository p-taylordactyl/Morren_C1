# Condition
*Source: Player's Handbook (2024) p. 363. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

A condition is a temporary game state. The definition of a condition says how it affects its recipient, and various rules define how to end a condition. This glossary defines these conditions:

- [Blinded](CLI/rules/conditions.md#Blinded)  
- [Charmed](CLI/rules/conditions.md#Charmed)  
- [Deafened](CLI/rules/conditions.md#Deafened)  
- [Exhaustion](CLI/rules/conditions.md#Exhaustion)  
- [Frightened](CLI/rules/conditions.md#Frightened)  
- [Grappled](CLI/rules/conditions.md#Grappled)  
- [Incapacitated](CLI/rules/conditions.md#Incapacitated)  
- [Invisible](CLI/rules/conditions.md#Invisible)  
- [Paralyzed](CLI/rules/conditions.md#Paralyzed)  
- [Petrified](CLI/rules/conditions.md#Petrified)  
- [Poisoned](CLI/rules/conditions.md#Poisoned)  
- [Prone](CLI/rules/conditions.md#Prone)  
- [Restrained](CLI/rules/conditions.md#Restrained)  
- [Stunned](CLI/rules/conditions.md#Stunned)  
- [Unconscious](CLI/rules/conditions.md#Unconscious)  

A condition doesn't stack with itself; a recipient either has a condition or doesn't. The [Exhaustion](CLI/rules/conditions.md#Exhaustion) condition is an exception to that rule.
